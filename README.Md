Система книжных отзывов

Назначение работы:
Приложение позволяет пользователям просматривать информацию о книгах, оставлять отзывы и оценки, а также видеть средний рейтинг каждой книги.

Целева аудитория:
Любители чтения.

Предметная область:
Книжный каталог с отзывами. Пользователи могут добавлять отзывы и оценки, система рассчитывает средний рейтинг.

Сущности:
Пользователь - человек, отсавляющий отзыв
Книга - предмет оценивания (содержит: название, отзыв, автор, рейтинг)
Отзыв - текст и оцентка (1-5).

Основные функции:
Координация пользователь по жанрам и поиск подходящих книг
Просмотр оценок и отзывов книг
Добавление книг в избранном

План развития
Добавление пользователей и аутентификации.
Хранение данных в базе данных.
Веб-интерфейс для просмотра и добавления отзывов.
REST API для интеграции.
Автоматическое тестирование.
